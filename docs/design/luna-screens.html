Luna — refined

Same concept, same mood. Tighter vertical rhythm, a smoother display face for the screen titles, and every icon re-checked against the thing it labels.

Rhythm

Composer to nav closed from 32px to 16px — the input now sits on the tab bar instead of floating above it.

Section labels 20/9 → 14/7, rows 12 → 10, thread gap 14 → 11.

Cards 26 → 24 radius with 16px padding; the step group is inset to align with Luna's text, not the screen edge.

Type

Manrope now sets every screen title, decision headline and stat — rounder bowls, softer terminals, and it matches the 22px corners far better than Inter did.

Inter stays for rows, labels and body, where its larger x-height is easier to read at 12–14px.

Titles up to 27px at -0.038em so the extra weight doesn't cost hierarchy.

Icons

Attach is a paperclip, not a plus.

Change folder is folder-plus, so it can't be confused with the folder rows below it.

"Won't run" now shows memory — the icon states the reason. Downloads use cloud-arrow-down, size cap uses weight, package.json gets the npm mark.
