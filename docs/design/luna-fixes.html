Six things you flagged, drawn. Same concept, same rhythm, no new colour: downloads you can pause and come back to, a cloud tab that knows who it is talking to, a paperclip that does something, a Save button the width of the word Save, and Models renamed to Model Zoo.

Downloads survive

Pause and resume on every download row, and inside the sheet.

Bad network parks the download at Waiting for signal instead of failing it.

Closing Luna does not lose progress: the .part file and byte offset are on disk, and it picks up with a Range request.

Model Zoo

The tab and the title now read Model Zoo.

Import a .gguf row at the top of On device, for a model already on the phone.

Stat tiles stop clipping: 880 MB / 3.5 GB.

Cloud, properly

Pick the provider first; the address fills itself in and locks.

Check models asks the provider what it actually serves, so no stale ids.

The list says when it was last refreshed, and flags a saved model that has disappeared.

WHAT THIS COMMITS TO IN CODE

Downloads

Progress lives on disk, not in memory: .part plus the byte offset, so a kill or a reboot loses nothing.

Pause is a real state, not a cancel. Resume sends Range: bytes=N-.

A foreground service keeps it going while you use other apps, with a notification you can pause from.

Imported models

SAF pick limited to .gguf, copied into the models directory so it survives a permission change.

Header read for the real parameter count and context length.

No hash to check against, so the row says not verified rather than implying it was.

Cloud

Provider first, address locked, key second, model last.

GET /v1/models on demand, cached with the time it was fetched.

A saved model missing from the list is flagged in the row, before a job depends on it.
